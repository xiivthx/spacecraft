# Follow-up disposition stubs

Greppable stubs for out-of-scope UX depth or interop limits at run/ship handoff. Not companion lanes; do not invent a register or slash command.

Must: Disposition stubs point Next: /sc-discuss without defining a full lane or register

## Post-ship UX depth

Prefix: `Post-ship UX depth:`

- `Post-ship UX depth: none`
- `Post-ship UX depth: follow-up - <short topic>`

End the stub block with `Next: /sc-discuss`.

## Interop / limitation

Prefix: `Interop/limitation:`

- `Interop/limitation: none`
- `Interop/limitation: follow-up-mission - <short topic>`

End the stub block with `Next: /sc-discuss`.
