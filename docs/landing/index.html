What it is

Decide before you build. Build before you ship.

Spacecraft is a local-first workflow for building with coding agents. You clarify intent in /sc-discuss, implement under /sc-run, then release with /sc-ship — without turning your repo into a cloud IDE.

Lanes stay sequential on purpose: decide before you build, build before you ship.

How to start

Three steps

  1. 01
    Install Follow the installation docs and open this repo in Cursor. Docs mirror offline — use GitHub fallback below.
  2. 02
    /sc-discuss Lock goal, verify, and (when visual) the draft.
  3. 03
    /sc-run Plan and implement against that spec; ship when ready.
